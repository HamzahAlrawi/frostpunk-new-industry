# Legacy Reconstruction cities

The version 3.15 supply-dispatch mode is retained for existing cities. New cities use the separate [Restoration, Whiteout and Machine Age modes](frontiers.md).

The [version 3.15 guide](https://github.com/HamzahAlrawi/frostpunk-new-industry/blob/v3.15.0/docs/reconstruction.md) records the unchanged legacy project budgets and route rules.
