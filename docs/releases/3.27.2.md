## Faultline building lookup and launch diagnostics

After the Frostland fix in 3.27.1, Frostpunk reached both maps and then crashed while looking up the Signal Relay, Coal Magazine, Valve Works and Relief Dispatch. The four prefab files were present in the archive. This hotfix registers their GUIDs and paths in the native `TemplateInfo.Bin` directory, which the engine uses to find them.

The owned-data audit checks that all original template catalog records and paths are preserved. Distribution QA resolves the four new GUIDs through the actual installed catalog and archive index and checks the prefab headers. All 70 tests and the mission simulations passed.

`py -3 builder/check_faultline_log.py` inspects Frostpunk's console output after it closes. It checks both map loads and the four prefab loads and reports common missing-template and serialization errors. It also accepts a captured console log as a path argument. A main-menu-only session fails the campaign check. The checker uses no desktop input. A fresh in-game Faultline run is still needed to confirm the fix in the engine.
