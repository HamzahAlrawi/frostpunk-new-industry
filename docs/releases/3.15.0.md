# New Industry 3.15.0 beta — Reconstruction

Adds an experimental fourth Endless mode that combines permanent reconstruction,
recurring relief shipments and optional industrial contracts. Start a new city
through **Endless → Reconstruction**. It uses Endurance maps and native weather.

- Twelve megaprojects consume progressively larger coal, wood, steel, ration and
  Steam Core budgets. Permanent rewards improve storage, industry, research,
  healthcare, food production and heating. The final project consumes 250,000
  coal, 80,000 wood, 100,000 steel, 60,000 rations and 1,200 cores.
- Three relief routes each develop through five levels. Deliveries trade large
  supplies for return cargo and continue at maximum level indefinitely. Missed
  deliveries preserve route infrastructure and offer a retry.
- Eighteen contract patterns across six grades offer optional three-day supply
  challenges. Accept or pass; the final grade continues indefinitely.
- Explicit dispatch choices recheck affordability before consuming resources.
  Untimed projects can wait while the city recovers. Native city variables,
  timers and quests hold mode state.

[Budgets, rewards and detailed rules](../reconstruction.md).

The builder now includes native binary/mode editors, scenario writers, an
independent decoder and a scenario simulation harness. Startup diagnostics
require thirteen relevant configurations and retain the first serialization
errors. Configuring starting stockpiles preserves the appended mode parameter.

Existing research, recipes, laws, prerequisites and tab layouts retain their
previous definitions. The original three Endless records and native event,
dilemma and quest records are preserved. The mode is disabled for ordinary
story/Endless games. No executable, ability-component or save patch is used.

## Validation and limits

59 automated tests pass. Owned-data checks cover all native/mod content and five
configuration presets. The independent mode decoder checks all 121 events, 80
dilemmas and 60 objective definitions, all delivery prices, duplicate/stale
payment rejection, isolation, timer cycles and 897 localized references in all
thirteen language tables. A 200-day model simulation completes 100 deliveries,
finishes all megaprojects and reaches the recurring endgame.

A bounded real startup loaded all thirteen required configurations with zero
serialization/decompression errors. The public installer round-trips all 37
patched entries and restores the six original archives exactly.

**The new mode-selection UI, a real delivery and real save/load have not been
verified. Computer control was stopped with Escape before that check. The
simulation does not establish in-game operation or campaign balance. This is an
experimental beta.**

Persistent configuration and original archive backups are retained.
