# New Industry 3.11.0 beta

Starting supplies are higher in every supported scenario and Endless mode.
All 17 native supply profiles receive the bonus, including missing resource
entries. Bonuses include rations and Steam Cores alongside wood, steel, coal
and raw food. Existing save inventories and scripted rewards are unchanged.

Five configurable presets range from **easiest** to **extreme**. A public first
installation defaults to **standard**, keeping the native difficulty menu in
control. The owner's local installation uses **easiest**: +200 wood, +150 steel,
+400 coal, +150 raw food, +100 rations and +5 cores per starting profile, before
native difficulty adjustments, with native Easy effects selected.

**Edit configuration.cmd** opens persistent settings. **Apply configuration.cmd**
rebuilds and verifies archives while Frostpunk is closed. Settings survive
updates. Individual resource bonuses, native difficulty categories, Workshop
output and mod perk research duration can be overridden. Defaults preserve the
1.5625 Workshop multiplier and half-duration mod research from 3.10.
See [configuration instructions](../configuration.md) for exact values.

Preset difficulty reuses native effects. Level identifiers, selection flags,
scenario scripts, abilities and building configs remain intact. Menu labels
remain native even when a config forces a category's effects. Start a new city
for new starting resources and difficulty settings.

Validation: 38 automated tests pass, including preset switching, invalid config
rejection, persistence, restoration and configuration-copy rollback. Owned-data
checks cover five presets, 17 supply profiles, 52 difficulty level records,
279 research duration offsets and unchanged scenario tails. The existing
validator checks 455 technologies, 812 modifiers, 43 recipes and eight scenario
graphs. Both standard and easiest passed full archive round-trip checks, with
all 32 patched entries verified and all six originals restored exactly. The
Windows executable deployed easiest locally; all seven required configs loaded
with zero serialization or decompression errors in a bounded startup check.
This remains a beta; startup checks do not test campaign balance.

Close Frostpunk, uninstall the previous release, then install this one. Select
a preset through config or `install --preset easiest`. Further configuration
changes to this release use **Apply configuration.cmd**.
