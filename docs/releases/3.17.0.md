# New Industry 3.17.0 beta — The Last Signal

**The Last Signal** is a standalone story scenario. A night telegrapher hears three settlements answering an old SOS. In four acts, choose which districts receive heat, build the facilities you promised, and run timed service shifts with the Generator on. Every route has a trade-off. Missed promises lead to a different epilogue, not a dead end. Each objective allows six to eight game days.

**Restoration, Whiteout and Machine Age** now have nine chapters each. Their optional second arcs build regional public works, a reserve heat grid or an independent machine district. The final operating trials spend supplies above an explicit reserve. Success grants a permanent district bonus. Existing founded cities are eligible for the proposal.

Whiteout gives new cities five days before the first front and caps the custom cold penalty at three insulation levels. Founding reserves are smaller, incident prices are lower, and doctrine bonuses and upkeep are less extreme. Quiet play suspends paid bonuses along with the bills.
