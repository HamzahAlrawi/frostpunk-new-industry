# New Industry 3.19.0 beta — Winter Road

The Last Signal now follows **eight main chapters** from the first two rescue convoys to the Long Night, with **six optional projects** and **three endings**. Rescues are the opening; follow-up chapters establish a district charter, survey the road, settle a coal dispute, run the crossing, and rebuild for a larger population.

The new game objectives check the actual temperature of finished homes, operating workplaces, scout return events, and new cooking and manufacturing. A completed Spare Rope project and a successful survey open a third plan for the crossing. The Apprentice’s Machine halves a real insulation penalty during the Long Night. Completing the watch and crossing unlocks a trade ending with three timed shipments.

[Winter Road player guide](../last-signal.md). Start a fresh city for the expanded story. The two previous versions of the story retain their records for existing saves.

The decoded-data audit runs six complete routes through the campaign, covering all 17 main mission variants, six projects, three endings, a run that misses every main deadline, both older story starts, and a failed heat inspection that resets the watch. It verifies both the Beacon map activation and the one-time scout return condition. These checks do not replace a live campaign playthrough.

All 66 public tests and the 39-entry installer round trip passed. A bounded startup of the installed build loaded all 13 required game configurations without serialization or decompression errors. The startup check did not open a city.
