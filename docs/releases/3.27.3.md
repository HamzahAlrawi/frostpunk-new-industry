## Signal Relay loading stall

Frostpunk found the Signal Relay prefab and stalled while reading its construction requirements. This update restores the missing headers before its scenario requirement. The building audit now reads the requirement from the native field boundary for each of the four Faultline prefabs. It rejects the 3.27.2 Signal Relay and accepts all four corrected release assets.

The scenario log checker stops at the first missing-template or serialization error and reports the most recently requested template. It can diagnose a repeating error without reading the remainder of a multi-gigabyte log. Run `py -3 builder/check_faultline_log.py` after closing Frostpunk, or pass a captured log as a path argument.

The automated tests, mission simulations, and installer checks passed. A fresh in-game Faultline launch still needs confirmation.
