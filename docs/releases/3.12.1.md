# New Industry 3.12.1 beta

Fixes core-research discoverability and the law-book layout reported in The Arks.

## Steam Core production

The four manufacturing technologies are now in the **first column of the added
Industry tab**, beginning with **Steam Core Fabrication at tier II (Drafting
Machines)**. They continue through Steam Core Assembly, Serial Core Production
and Core Fabrication Cells. Select the unlocked recipe at a Factory to make cores.
The chain was present in The Arks in 3.12, but located in the last Production tab.
Research identifiers, recipe costs, durations and the three-core batch remain
unchanged. Arks membership and the serialized placement now have regression checks.

## Native law books restored

Charters are additional nodes in **Adaptation**, or **Administration** in The
Last Autumn. They occupy a spaced upper row above the native branches; pan or
zoom upward if needed. They no longer share the book emblem's centre.

The four native books retain their original indices, bytes and unlock conditions:
Purpose, Adaptation, Labour and Administration. All 112 native law definitions
also retain their original order and contents. Order/Faith access follows the
original scenario's Purpose unlock rules; this update does not grant Purpose to
scenarios that normally lack it.

The Arks normally has no Purpose (Order/Faith) laws; see the
[scenario reference](https://frostpunk.fandom.com/wiki/The_Arks).

The former Civic Charters category is appended, hidden compatibility data with
no active laws. It cannot take the first native book slot. Original charter IDs
are retained for existing signed-law progress. Autumn has four equivalent entries
in its civil book; signing is blocked if the same policy was already granted by
the 3.12 legacy entry. This is still four policies per scenario, not eight perks.
No save files are rewritten.

## Validation

45 automated tests pass. Owned-data validation checks the actual charter positions
against every native node and the central book emblem. It verifies native book
and law order, unlock predicates, preserved charter IDs and the actual Arks core
branch. Removing the additions reconstructs the entire pristine society config
byte for byte, including the 89 unlabelled bytes after its law vector.

The normal validator checks 462 technology records, 825 modifiers, 43 production
recipes and eight scenario graphs. Difficulty presets and research pacing retain
the previous defaults. Archive install/uninstall validation uses an isolated
workspace copy; all 33 patched entries and exact restoration of six archives
passed. No live game UI check is performed for this patch; it remains beta.

Close Frostpunk, uninstall the previous version, then install 3.12.1. Persistent
configuration and original archive backups are retained.
